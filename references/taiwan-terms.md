# 台灣用語

以台灣讀者習慣的詞彙起稿，再逐句檢查語境。這是本 skill 的地區用語選擇，不是對所有台灣人的喜好做推論，也不用在成品裡評論其他地區的說法。

## 檢查方式

1. 先辨認原句的詞義，再選台灣慣用詞。下表是常見軟體、網站與文案情境的起點，不做全文機械取代。
2. 保留產品名稱、程式識別字、引用及使用者實際會看到的介面標籤。若文件正在教一套簡中介面，步驟中的按鈕名稱照畫面寫，必要時補充說明。自己正在修改該介面的台灣版字串時，才一起本地化。
3. 同一個意思，在同一產品與文件中用同一個詞。交稿前查閱每個疑似跨地區詞，確認已改成適合本句的用字，或有明確的保留理由。遇到生僻術語，優先查專案詞彙表、台灣專業資料或該產品的台灣版文件。

## 常見對照

左欄列常見的中國大陸用法及其繁體形式，供辨識使用。

| 遇到的用字 | 台灣文案優先考慮 | 語境 |
| --- | --- | --- |
| 软件／軟件 | 軟體 | software |
| 代码／代碼 | 程式碼 | code；「代碼」仍可指識別代號 |
| 程序 | 程式 | 電腦程式；保留「申請程序」 |
| 文件、文件夹 | 檔案、資料夾 | file、folder；document 仍可稱「文件」 |
| 文档／文檔 | 文件、說明文件 | documentation |
| 默认／默認 | 預設 | default；「默認這個安排」另論 |
| 设置 | 設定 | settings |
| 内存／內存 | 記憶體 | RAM；disk storage 為儲存空間 |
| 硬盘／硬盤 | 硬碟 | storage device |
| 服务器／服務器 | 伺服器 | server |
| 缓存／緩存 | 快取 | cache |
| 加载／加載 | 載入 | loading content |
| 保存 | 儲存 | save action；保留「保存期限」 |
| 创建／創建 | 建立、新增 | 依操作是建立物件還是新增項目 |
| 登录／登錄 | 登入 | sign in；保留「登錄資料」的登記意思 |
| 注册／註冊 | 註冊 | 可直接保留，並非兩地每個詞都不同 |
| 链接／鏈接 | 連結 | hyperlink |
| 网络／網絡 | 網路 | internet/network；人際脈絡依領域用詞 |
| 视频／視頻 | 影片、視訊 | 播放影片；即時通話用「視訊通話」 |
| 音频／音頻 | 音訊、音檔 | audio signal / audio file 分開判斷 |
| 屏幕 | 螢幕 | display |
| 鼠标／鼠標 | 滑鼠 | pointing device |
| 菜单／菜單 | 選單 | UI menu；餐廳仍是「菜單」 |
| 打印 | 列印 | print |
| 激活 | 啟用 | activate feature；依實際操作也可能是「開通」 |
| 支持 | 支援 | 相容性、功能；保留「支持這個決定」 |
| 信息 | 資訊、訊息 | information / message 分開判斷 |
| 质量／質量 | 品質 | quality；物理量 mass 仍是「質量」 |
| 反馈／反饋 | 回饋、回報 | 意見回饋；回報問題；專業術語另查 |
| 优化／優化 | 改善、最佳化、調整 | 寫清楚改了什麼；數學最佳化保留精確名稱 |
| 运营／運營 | 營運、經營 | 營運服務、經營社群 |
| 充值 | 儲值 | 帳戶加值，依產品既有名稱 |
| 跳转／跳轉 | 前往、導向、重新導向 | 按鈕動作與 HTTP 行為分開寫 |

「數據、支持、菜單、水平、質量」都可能有正常的台灣語境。即使某詞出現在網路上的用語黑名單，也要先看本句意思。流行語的接受程度差異更大，使用者沒有提供這種口氣時，用「划算、推薦、好看、很實用」等直接描述，並讓評價有內容依據。

## 對照練習

原稿：「默認支持上傳視頻，點擊鏈接即可查看文件。」

台灣版：「預設支援上傳影片，點選連結即可查看檔案。」

原稿：「我們支持這項決定。這份文件附有餐廳菜單，以及測量物體質量的實驗紀錄。」

保留原句。這裡的「支持、文件、菜單、質量」各有明確意思。

[Dcard 的用語討論](https://www.dcard.tw/f/mood/p/260032494)搜尋索引中可見對視頻、信息、屏幕等詞的不滿。這只能證明部分讀者在意這些差異，不能當作所有人的用語規範。表格其餘選擇包含編輯判斷；產品本身的台灣詞彙表與實際語義仍優先。
