# 台灣繁中標點檢查

以下為原創人工檢查題，尚未記錄模型測試結果。記錄方式見 [README](README.md)。

| 提示 | 檢查重點 |
| --- | --- |
| 幫我順一下傳給朋友的訊息，第一行是「我到樓下了」，第二行是「你慢慢來」。保留輕鬆口氣。 | 可以維持換行與無末尾句號，不必改成正式通知。 |
| 修一下要貼在 Dcard 的交通攻略：「去程在前門上車，刷卡付費；回程在後門上車，下車再付費。」 | 不因發表平台而刪掉分號或句號。若拆句，必須保留去回程不同的上車處與付費時機。這是虛構練習，不是實際交通資訊。 |
| 幫我看網站公告：「週六暫停服務。週日恢復營業。」 | 已清楚，可以不改；不能把「網路少用句號」當成全面刪除規則。 |
| 編輯小說：「我到樓下了。」她說。 | 保留對話及敘述層次，不套聊天訊息的省略方式。 |
| 修改這則留言，但保留原本驚訝的語氣：「居然真的拍到了！！」 | 可以保留重複驚嘆號，不自動轉成冷淡陳述或添加表情。 |
| 寫台灣 app 的標題、說明、按鈕：檔案超過 10 MB，可以重新選擇。 | 按鈕與短標題可無句號，完整說明照產品體例；不新增格式限制。 |
| 改寫說明，保留實際按鈕名及指令：「點擊『Save...』，再執行 `SELECT 1;`。」 | 引號外可改成台灣用語；不得更改標籤內的點或 SQL 分號。 |

## 段落、句子與連接詞

檢查 [段落、句子與清單](../references/languages/zh-TW/composition.md) 的規則。以下也是原創人工檢查題。

| 原稿 | 檢查重點 |
| --- | --- |
| 用 native-writing 修改這段 API 說明：「此外，您也可以設定逾時。因此，請求會在三秒後停止。然而，重試的次數不受影響。」 | 拿掉或換掉句首的「此外」「因此」「然而」，關係改由語序或「就」「但」交代。保留三秒、會停止、重試次數不受影響。不新增原因。 |
| 用 native-writing 修改：「報名成功後系統寄出的包含活動時間地點與報到 QR code 的確認信可能會被歸類到垃圾郵件匣中。」 | 拆開堆在「確認信」前面的修飾語。保留「可能」，不改成確定會進垃圾郵件匣。保留時間、地點、QR code 三項內容。 |
| 用 native-writing 修改：「登入後點選右上角的頭像，進入設定頁，就能修改顯示名稱。」 | 這是同一件事的步驟，用逗號串成一句是自然的中文。保持原樣是合適的。 |
| 用 native-writing 改寫這則給所有參加者的報到公告：「本次活動地點為台北市信義區松仁路 100 號，報到時間為上午九點至九點半，請攜帶身分證件及報名 QR code。」 | 每行只放一個資訊，地點、報到時間、要攜帶的東西分開。保留完整地址、九點到九點半、身分證件和 QR code。 |
