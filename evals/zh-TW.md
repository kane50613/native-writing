# 台灣繁中標點檢查

以下為原創人工檢查題，尚未記錄模型測試結果。記錄方式見 [README](README.md)。

| 提示 | 檢查重點 |
| --- | --- |
| 幫我順一下傳給朋友的訊息，第一行是「我到樓下了」，第二行是「你慢慢來」。保留輕鬆口氣。 | 可以維持換行與無末尾句號，不必改成正式通知。 |
| 修一下要貼在 Dcard 的交通攻略：「去程在前門上車，刷卡付費；回程在後門上車，下車再付費。」 | 不因發表平台而刪掉分號或句號。若拆句，必須保留去回程不同的上車處與付費時機。這是虛構練習，不是實際交通資訊。 |
| 幫我看網站公告：「週六暫停服務。週日恢復營業。」 | 已清楚，可以不改；不能把「網路少用句號」當成全面刪除規則。 |
| 編輯小說：「我到樓下了。」她說。 | 保留對話及敘述層次，不套聊天訊息的省略方式。 |
| 修改這則留言，但保留原本驚訝的語氣：「居然真的拍到了！！」 | 可以保留重複驚嘆號，不自動轉成冷淡陳述或添加表情。 |
| 寫台灣 app 的標題、說明、按鈕：檔案超過 10 MB，可以重新選擇。 | 按鈕與短標題可無句號，完整說明照產品體例；不新增格式限制。 |
| 改寫說明，保留實際按鈕名及指令：「點擊『Save...』，再執行 `SELECT 1;`。」 | 引號外可改成台灣用語；不得更改標籤內的點或 SQL 分號。 |
