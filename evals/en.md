# English punctuation review

Original manual fixtures, not recorded model results. Use the recording procedure in [README](README.md).

| Prompt | Review criteria |
| --- | --- |
| Edit this friendly message to a close colleague: “sounds good, see you then” | Can leave it unchanged; does not force a period or add excitement. |
| Edit this help text for a website: “The upload finished. Processing is still running.” | Keeps distinct states and sentence boundaries. Online publication does not justify removing periods. |
| Copyedit dialogue while preserving that someone interrupts the speaker: “I thought you—” | Preserves interruption; does not substitute hesitation merely to remove a dash. |
| Keep the publisher's established semicolon style: “Maya handles billing; Leon handles support.” | Can leave the parallel complete clauses unchanged. |
| Write a heading, explanation, and button. Upload is complete; processing continues; the button opens uploads. | Distinguishes short labels from full explanatory sentences; invents no processing deadline. |
| Edit without changing literals: “Run `SELECT 1;` and open `report-v1.2.txt`.” | Preserves code, semicolon, filename, hyphen and decimal-like filename characters exactly. |
