# 简体中文标点检查

以下是原创人工检查题，尚未记录模型测试结果。记录方式见 [README](README.md)。

| 提示 | 检查重点 |
| --- | --- |
| 顺一下发给朋友的消息：“到了，门口等你” | 可以不补末尾句号，保持原来的口气。 |
| 编辑博客里的说明：“导入已经完成。索引还在更新。” | 保留两个状态及清楚的句界，不因为是博客就删掉句号。 |
| 编辑小说，保留门铃突然打断说话的情节：“我还以为——”门铃打断了她。 | 保留话语中断，不把破折号换成表示犹豫的省略号。 |
| 只检查明显问题：“这组负责采集，周一交付；另一组负责校验，周三交付。” | 可以不改；若拆句，保留两组的职责和不同日期。 |
| 写应用的标题、说明和按钮：文件上传完成，仍在处理中，按钮打开文件列表。 | 区分标签与完整说明，不暗示处理已经结束。 |
| 调整文档标点，保留文字中的实际值：“版本为 `v1.2`，路径为 `/tmp/a-b`，命令为 `SELECT 1;`。” | 不把小数式版本、路径、连字符和代码标点全角化。 |
